# Librarium

**Your books, beautifully kept.**

A gorgeous home for your ebooks, and a one-click road to your Kindle or Kobo.

## How it works

1. **Pick a folder.** On your computer, an external drive or a NAS: your
   library is just that folder, nothing locked away.
2. **Drop your books in.** EPUB, PDF, MOBI, AZW3, CBZ. Librarium reads
   their covers and details; one click finds what's missing online.
3. **Plug in your e-reader.** Select books, hit *Send*. Kindle or Kobo, the
   right format is made for you.

## What's inside

|   |   |
|---|---|
| 📚 **A library that feels like one** | Real covers, a grid or a list, search, filters, favorites first. Fast with thousands of books. |
| 📲 **Kindle & Kobo, plugged in** | See what's on the device and how far you've read, send books, bring them back. |
| ✨ **Tidy metadata** | Find covers and details online, review every change, edit a whole series at once. |
| 📖 **Read right there** | A built-in reader for EPUB, PDF, MOBI and AZW3. |
| 🌍 **More books** | Search Project Gutenberg, Open Library and OPDS catalogs; share your library with reading apps like KOReader. |
| 👥 **For the whole family** | One library per reader, and the lot backed up in a single file. |
| 🎨 **Four themes** | Each dressed like a book cover: Nocturne, Saphir, Folklore, Cerulean. |
| 🔒 **Yours, and only yours** | No account, usage statistics only if you say yes. Deleted books go to the Trash, never lost. |
